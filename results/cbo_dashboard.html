Oracle Gap Decomposition — Run C (671k fixed, θ*=0.16)

Per-filter oracle gap = routing error (fixable) + irreducible per-query variance

Routing error (wrong θ* → wrong arm in expectation) Irreducible gap (per-query PostFilter recall variance — unfixable by any threshold)

Three filters have routing errors: sel=15.93% (predictor overestimates as >16%, routes to PostFilter instead of bitmap, error=0.316), sel=20.97% (bitmap better but θ*=16% sends to PostFilter, error=0.209), sel=23.42% (bitmap barely better, error=0.039).
Global oracle gap 0.105 = routing error 0.019 + irreducible floor 0.085. After the pending last-crossover fix (θ*≈0.26), routing error drops to ~0.007 → total gap ~0.093.
